# 知识库（site-chat 插件用）

这里放 AI 客服的问答素材。文件随 `install.ps1` 同步到 `wp-content/plugins/site-chat/data/knowledge/`。

## 文件

| 文件 | 来源 | 说明 |
| --- | --- | --- |
| `products.json` | **脚本生成，不要手改** | 由 `rococo-core/includes/kb-export.php` 从 123 款产品导出 |
| `faq.json` | 人工维护 | 发货、运费、样品、安装、售后等问答 |

## 重新生成 products.json

```powershell
$env:ROCOCO_KB_OUT = "C:\Users\win\.codex\worktrees\07b9\WP\rococo-site\data\knowledge\products.json"
& D:\wp-tools\php82\php.exe D:\wp-tools\wp-cli.phar --path=D:\WP\rococoeco eval-file D:\WP\rococoeco\wp-content\plugins\rococo-core\includes\kb-export.php
```

然后跑 `rococo-build/install.ps1 -Stage plugin`（或 `-Stage all`）同步到站点。

## 条目结构

产品条目（脚本生成）：

```json
{
  "id": "product-1949",
  "type": "product",
  "code": "HS1228",
  "title": "HS1228 木纹 中性色",
  "url": "http://…/products/hs1228",
  "fields": { "产品编号": "HS1228", "规格": "2400×900/1200mm、…" },
  "keywords": ["HS1228", "墙板", "木纹", "中性色"]
}
```

人工问答条目：

```json
{
  "id": "faq-shipping",
  "type": "faq",
  "title": "发货与物流",
  "question": "多久能发货？怎么发？",
  "answer": "……",
  "keywords": ["发货", "物流", "运费"],
  "status": "draft"
}
```

## 两条规则

1. **`status: "draft"` 的条目默认不参与回答**。业务口径没确认前留在 draft，客服遇到相关问题会自动走邮件兜底，而不是编造。
2. 顶层可以是数组，也可以是 `{ "items": [...] }`，插件两种都认。
